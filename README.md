# BYOMKESH - Cloud Enabled System Monitor

A real-time system monitoring dashboard built with Python Flask.

**Features:**
1.  Live CPU, RAM, Disk Monitoring
2.  Cloud Service Status Check - AWS, Google, GitHub
3.  Real-time Chart using Chart.js
4.  Alert System for High Usage
5.  SQLite Database for data history

**Tech Stack:** Python, Flask, SQLite, psutil, requests, Chart.js

**Run Locally:**
1. `pip install -r requirements.txt`
2. `python app.py`
3. Open `http://localhost:5000`
